# GitHub 客户端

只读 GitHub 的静态单页：一个 HTML 文件，浏览器打开即用。

![首页](docs/screenshots/home.png)

## 为什么是它

**网页版，什么都不用装。**
一个文件，双击就开；放到任何静态托管上就是一个可以分享的网址。没有安装包、没有更新提示、没有后台进程。手机、平板、Windows、macOS、Linux 都一样。

**轻。**
308 KB，比一张手机照片还小。markdown 渲染、语法高亮、样式与全部逻辑都内联在里面，断网时界面照样打开，只是没有内容。

**绕开常断的那条路。**
它不加载 GitHub 的任何前端资源，只调 `api.github.com`。三条通路（直连 / 自建中转 / 公共中转）按探测结果排序，主路不通自动走备路，不用装 VPN，也不用改 hosts、改 DNS。

**省额度。**
文件正文与 README 图片走 raw 通道，不计入 API 配额；重复访问命中本地缓存，一个请求都不发。浏览一个仓库通常只消耗 3 次调用。

**零后端。**
没有服务器会挂，没有数据库要维护，没有环境变量要配。静态托管的免费额度足够跑，本地双击也能用。

**只读，所以安全。**
不接受 star、发 issue、push 这类写操作，令牌不必带写权限。凭据只存在你自己的浏览器里——这个页面没有服务器，也就没人能截走它。

## 和其他方式比

| 方式 | 代价 |
| --- | --- |
| 官方网页 | 前端资源重，网络差时白屏，且本身就打不开 |
| 桌面客户端 | 要安装、要更新，体积以百 MB 计 |
| 命令行 `gh` | 功能齐全，但看代码没有高亮与排版 |
| 第三方镜像站 | 他人运营，可能关停或注入内容，中间过程不可见 |
| 本项目 | 一个静态文件，自己托管，代码全部可读 |

## 搜索

点开顶栏的搜索会铺开整块面板，类型与筛选条件一次挑完，回车即走。

![搜索面板](docs/screenshots/search-panel.png)

四类结果各有独立条件，条件写进 URL，所以能刷新、能分享：

| 类别 | 可调条件 |
| --- | --- |
| 仓库 | 排序（Star / Fork / 更新 / 待协助）、语言、Star 下限、更新时间 |
| 代码 | 语言、限定仓库 `owner/repo`、路径前缀；命中片段内高亮关键词 |
| 用户 | 排序（关注者 / 仓库数 / 加入时间）、用户或组织、仓库数下限 |
| 议题 | 排序、状态、仅议题或仅 PR、标签 |

结果页会显示**实际发给 GitHub 的检索式**，条件拼没拼对一眼可见：

![搜索结果](docs/screenshots/search-results.png)

粘 `github.com` 的链接进去则直接跳到对应页面，不走搜索：

| 粘进来的链接 | 去往 |
| --- | --- |
| `github.com/o/r` | 仓库首页 |
| `.../blob/<分支>/<路径>` | 文件 |
| `.../tree/<分支>/<路径>` | 目录 |
| `.../issues`、`.../issues/12` | 议题列表 / 议题 |
| `.../pulls`、`.../pull/34` | PR 列表 / PR |
| `.../releases`、`.../commits`、`.../branches`、`.../commit/<sha>` | 对应标签页 |
| `github.com/<用户>` | 用户主页 |
| `raw.githubusercontent.com/...` | 文件 |

不带协议也认。首页的「从剪贴板打开」省去粘贴这一步。

## 翻译

英文为主的介绍，标题栏会多出一个「译成中文」按钮，译完可一键切回原文。

两条通道按可用性自动选：

| 通道 | 特点 |
| --- | --- |
| 浏览器内置翻译模型 | Chrome 138+ / Edge 自带，本地运行，不限量，内容不出本机 |
| MyMemory | 免配置的公共接口，500 字符/次、约 5000 字符/天 |

译文按「仓库@分支」缓存在本机，同一仓库只翻一次。若自建了 LibreTranslate，在设置里填地址即可绕开上面两个限制。

翻译只作用于正文段落，代码块、链接地址、表格分隔符原样保留。

## 通路

请求按顺序尝试，任一失败切下一条：

| 通路 | 地址 | 前提 |
| --- | --- | --- |
| 直连 | `api.github.com` | 网络可达 GitHub |
| 自建 | 自填，见 `worker.js` | 有自己的 Cloudflare Worker 或反代 |
| 公共 | `gh-proxy.org` → `gh-proxy.com` | 无需配置；额度由该站共享，可能被用尽 |

文件内容与 README 图片另走 raw 通道（`raw.githubusercontent.com` → `gh-proxy.org` → `gh-proxy.com` → `ghfast.top` → API 二进制），不占 API 额度。因此 API 完全不可用时，仍能浏览已进入的仓库文件。

探测端点用 `/rate_limit`，不消耗额度。顶栏徽标显示当前通路与延迟，绿色为直连或自建，黄色为公共中转。

## 本地缓存

浏览过的响应存在 `localStorage`，有效期内再次访问不发请求，因此不消耗配额。

| 内容 | 有效期 |
| --- | --- |
| 文件、目录、搜索 | 5–10 分钟 |
| 提交、议题、PR | 4–5 分钟 |
| 仓库信息 | 8 分钟 |
| 发行版、分支 | 15 分钟 |
| 用户主页 | 20 分钟 |
| README | 30 分钟 |

换令牌会清空缓存（可见范围变了）。设置面板里能看到条数，也可手动清空。

## 用法

打开后填一次访问令牌即可（右上「未授权」）。面板里可以直接跳到 GitHub 的令牌生成页（已预填 `public_repo,read:org` 作用域），也可以复制 `gh auth token` 命令到终端取现成的。

| 项 | 匿名 | 带令牌 |
| --- | --- | --- |
| 核心接口额度 | 60 次/小时 | 5000 次/小时 |
| 代码搜索 | 不可用 | 可用 |
| 私有仓库 | 不可用 | 可用 |

已支持：仓库浏览、目录树、文件查看与语法高亮、README 渲染、Markdown 预览、语言占比、Issue / PR 只读、评论正文、提交历史、发行版、分支、用户主页、按仓库生成下载与克隆地址。搜索结果、议题列表、提交历史都支持翻页。

快捷键：`/` 或 `Ctrl+K` 打开搜索面板，`Esc` 关闭。

## 边界

- 只读。开 issue、star、push 等写操作不在此处完成。
- 无后端。所有请求由浏览器直连 GitHub 或用户指定的中转，没有中间服务器。
- 令牌存在浏览器 `localStorage`，随请求直接发往 GitHub。走公共中转时该服务能看到请求头，介意就用直连或自建。以 `file://` 打开时，同浏览器的其他本地页面也能读到该令牌，长期使用建议部署成站点。
- 私有仓库、代码搜索依赖令牌权限；令牌需带 `repo` 与 `read:org` 作用域。
- 单页约 318 KB，依赖全部内联，断网也能打开界面。

## 部署

纯静态，无构建步骤：

| 平台 | 做法 |
| --- | --- |
| Cloudflare Pages | 上传 `GitHub.html`，改名 `index.html` |
| Vercel / Netlify | 同上，或拖整个目录 |
| 自有服务器 | 放进 web 根目录 |

### 自建中转

公共中转的额度不受自己控制，长期用建议自建：

1. 在 Cloudflare 新建 Worker，粘贴 `worker.js` 内容，部署。
2. 复制 Worker 地址（`https://xxx.workers.dev/`）。
3. 填入客户端「设置 → 自建中转」，点保存。

Worker 只转发白名单内的 GitHub 域名，避免被当作开放代理滥用；用户令牌原样透传，额度是独立的。

Nginx 亦可替代，把 `/https://api.github.com/...` 转发到上游并补上 `Access-Control-Allow-Origin` 与 `Access-Control-Allow-Headers` 即可。

## 构建

修改 `src/` 或 `vendor/` 后重新生成单文件：

```
node build.js
```

## 文件

```
GitHub.html           成品，单文件，可直接部署
worker.js             Cloudflare Worker 中转
build.js              把 src 与 vendor 内联成单文件
src/shell.html        外壳模板
src/style.css         样式
src/app.js            应用逻辑
vendor/               marked、highlight.js
docs/screenshots/     界面截图
scripts/push-api.js   git 通道不通时经 API 推送（维护用）
```
