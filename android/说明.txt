GitHub 客户端 APK（v1.0.2）
=============================

把 github-client 的单文件网页打包成安卓应用，网页内置在安装包里，
不部署、不依赖任何在线服务。应用内的 GitHub 请求由页面直连 api.github.com。
页面文件与网页版构建产物逐字节相同，功能无删减。

安装
----
1. 把 GitHub客户端-v1.0.2.apk 传到手机（数据线、微信文件传输等均可），
   也可从仓库 android/apk/ 目录直接下载 GitHubClient-1.0.2.apk。
2. 点击安装；系统提示「未知来源应用」时允许本次安装。
3. 首次打开后在设置里填入 GitHub 令牌，与网页版相同。

包信息：com.pangyiwen.ghclient，versionCode 10002，minSdk 24（Android 7.0+）。
图标为自适应图标（Android 8.0+），旧系统回退为矢量图标。

缩放
----
内容区支持两种放大缩小方式：

- 双指捏合：WebView 自带手势，连续无级缩放；
- 右下角悬浮按钮：＋ / － 两级步进，与捏合共用同一套缩放引擎。

缩放只改变显示比例，不重排内容；文字始终按矢量重新渲染，放大后不失真。
页面里的模态框（设置面板等）打开时，悬浮按钮自动收起，避免压在弹窗上
（通过 MutationObserver 监听 modal 的 hidden 属性，无轮询）。

setTextZoom(100) 固定排版基准，系统字体大小不会影响布局；
需要更大字号时用缩放控件，或调整系统字体设置后重开应用。

更新（两条通道，均从本仓库拉取）
--------------------------------
1. 页面更新：每次打开发起一次版本检查，读取仓库的 VERSION 文件
   （raw → gh-proxy.org → gh-proxy.com 逐级尝试，与网页版同一条降级链）；
   发现新版本时弹窗询问，确认后下载最新 GitHub.html，校验通过后就地替换并刷新。
2. 安装包更新：读取 android/apk/version.json，versionCode 高于已安装版本时弹窗询问，
   确认后经 DownloadManager 下载，完成自动调起系统安装器。
   首次使用需在系统设置里授予本应用「安装未知应用」权限（Android 8.0+），
   缺权限时会自动跳转设置页。

安装包自带的页面与磁盘上的不一致时，以安装包为准（按文件长度判断，
同长度不同内容的极端情况重新安装可强制刷新）。

网页自身的更新入口已关闭（assets/boot.html 在页面前执行写入 ghl_upd_on=0），
页面更新由原生通道承担，避免双重弹窗。

与网页版的差异
--------------
页面逐字节相同，以下为外壳行为差异，均有对应实现：

- confirm() 确认框（删除 Gist、删除发行版）：WebView 默认不弹，
  已由 WebChromeClient 接管为原生对话框；
- 剪贴板：navigator.clipboard 在旧版 WebView 上可能不可用，
  复制走 execCommand 兜底，读取失败转为打开搜索面板；
- 站外链接（原网址、README 外链）交系统浏览器打开，不在应用内加载。

重新出包
--------
网页或外壳更新后：

1. 用新的 GitHub.html 覆盖 assets/index.html；
2. 修改 AndroidManifest.xml 里的 versionCode / versionName；
3. 双击 build-apk.bat，产物为 GitHubClient.apk；
4. 把安装包复制为 android/apk/GitHubClient-<版本>.apk，
   并同步更新 android/apk/version.json 后提交。

构建环境用本机已有的 C:\build-mv47（JDK 17 + Android SDK 36.1），
不写注册表、不改 PATH。

签名密钥在 build\ghclient.jks（已被 android/.gitignore 排除，不会提交），
同一个包名覆盖安装必须用同一个密钥，请勿删除；建议单独备份，
遗失后旧安装包无法原地升级，只能卸载重装。

已知边界
--------
- 页面从应用可写目录加载，localStorage 来源与 10-25 14:00 之前的版本不同：
  装过那些版本的需重新填一次令牌。
- 返回键先走应用内的 hash 路由历史，无历史可退时退出应用。
- 未在真机安装验证过；如遇白屏，检查系统 WebView 版本（应保持较新）。

清理
----
删除本文件夹即可移除全部构建产物。C:\build-mv47 为多个项目共用的
Android 工具链，删除会影响其他项目的构建。
